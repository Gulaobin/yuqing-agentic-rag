# 证据引用规范

## 证据类型

| 类型 | 编号格式 | 示例 |
|---|---|---|
| 规范与方法文档 | STD-编号、MTH-编号 | STD-004 |
| 历史复盘 | CASE-编号 | CASE-003 |
| 事件 | EVT-编号 | EVT-0007 |
| 帖子 | P事件序号-帖子序号 | P0007-0024 |
| 账号 | A编号 | A00166 |

## 引用要求

- 引用业务记录时，编号必须来自本次查询实际返回的结果，不得凭印象填写。
- 统计结论要说明是对哪些记录做的统计，例如「EVT-0015 第 0–23 小时的全部帖子」。
- 同一结论有多条证据时，列出最直接的一到三条即可。
