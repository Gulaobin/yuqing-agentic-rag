# 业务数据说明

## 数据范围

业务库是只读的 SQLite 数据库，记录事件、帖子、账号和逐小时指标。时间均为北京时间，格式为 YYYY-MM-DD HH:MM:SS。每个事件只保留首帖之后 72 小时内的帖子。

## 表与字段

| 表 | 主要字段 |
|---|---|
| events | event_id 事件编号、title 标题、topic 主题、level 等级（1–4）、status 状态、first_seen_at 首帖时间 |
| posts | post_id 帖子编号、event_id、account_id、platform 平台、created_at 发布时间、text 正文、sentiment 情感、parent_post_id 被转发帖编号 |
| accounts | account_id 账号编号、platform、created_at 注册时间、followers 粉丝数、verified 是否认证（1 为认证） |
| metrics_hourly | event_id、hour 第几小时（0–71）、hour_start 该小时起点、post_count 帖子数、repost_count 转发数、unique_accounts 去重账号数 |

## 不包含的信息

业务库不记录责任单位、官方回应内容、账号昵称和真实身份。涉及这些信息的问题按 STD-010 处理。
