# 热度计算口径

## 逐小时帖子数

以事件首帖时间为第 0 小时起点，把首帖之后 72 小时划分为第 0 到第 71 小时，每小时统计一次。

- 帖子数：该小时内发布的全部帖子，包含原帖和转发。业务库字段为 metrics_hourly.post_count。
- 转发数：其中的转发帖数量，字段为 repost_count。
- 去重账号数：该小时内发过帖的不同账号数量，字段为 unique_accounts。

本规范所说的「热度」即逐小时帖子数。

## 峰值小时

72 小时内帖子数最多的那个小时为峰值小时。帖子数相同的多个小时中，取最早的一个。

## 总量

72 小时帖子总数等于各小时帖子数之和，用于确定事件等级（见 STD-001）。
